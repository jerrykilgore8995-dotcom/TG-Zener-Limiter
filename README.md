# TG12413 Zener Limiter — Windows VST3

JUCE 8 stereo TG-style zener limiter project, with the original measured DSP reference grid and EMI TG12413-style GUI. Build is performed by GitHub Actions using Windows/MSVC.

The complete source archive is uploaded alongside `.github/workflows/windows-vst3.yml`. This repository is a work in progress until a successful Windows build has been verified.
